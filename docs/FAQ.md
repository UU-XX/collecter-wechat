# 常见问题

## 三种方式需要都安装吗？

不用。CLI 适合直接使用，Python 适合查看源码与脚本运行，Skill 适合在 AI 助手中组织完整任务。Skill 会携带必要业务脚本，不要求另装 CollecterCLI；宿主仍需满足声明的执行环境。

## 支持哪些系统？

当前微信读取链路面向 Windows，CLI 程序面向 x64。Python 源码采用已验证的 64 位 Python 3.12 环境。Skill 不会让底层读取能力自动变成跨平台，不能据此承诺 macOS 或 Linux 直接读取微信。

## 必须有模型或 API Key 吗？

普通导出、浏览和统计不需要。Python / CLI 的模型总结需要配置相应接口；本地无认证模型服务可以不填 Key。Skill 使用其宿主已有的 AI 能力，不以另配一份 Collecter 模型密钥作为默认前提。

## 为什么找得到账号目录，却读不到会话？

历史目录不代表当前登录。先确认微信已打开、账号目录正确，并与 Collecter 使用相同 Windows 用户和适当的权限级别。缓存不足时，可能需要明确允许本次数据库密钥读取。

## 为什么导出成功，仍不能保证历史完整？

工具只能导出本机存在且可读的记录，不能从云端补齐缺失历史。请结合 `采集说明.json` 的时间范围、分片覆盖、解析失败和快照说明判断结果。

## 模型提示 OUTPUT_LIMIT 是什么？

模型接口返回生成达到输出或上下文上限。当前支持省略预算的协议默认不设置本地 token 限额，接口自身仍有默认值和最大值。诊断中的 `provider_default_budget=true` 表示本次使用接口默认值；`requested_max_tokens` 表示实际发送的预算。

程序不会把不完整正文标成完整总体总结，也不会自动重发失败请求。

## 没有总结，但有统计报告，算成功吗？

说明本地统计已经生成，模型分析未必完成。查看“模型分析状态”、已完成日期和 `模型诊断.jsonl`；已完成请求数不等于完成整天数。

## 中途失败后，能接着分析吗？

模型片段级断点续跑尚未实现。完整每日总结会保留，但重新生成报告可能重做此前片段。导出任务已有的增量和续导不代表模型分析也支持同样恢复。

## 一年记录会先按月、再按年总结吗？

当前 Python / CLI 实现仍是每日 → 总体汇总，不设总天数门槛。月度与年度层级尚未实现。Skill 首发也不能在没有相应实现和验证时承诺这项能力。

## 能导出图片、识别语音吗？

当前不导出图片文件，不提供 OCR 或语音识别。视频和文件附件是可选能力，依赖本机已有资源与明确关联，不能保证所有编码和附件都可导出。

## TOOL_CHECK 怎么处理？

使用完整源码包或完整解压的 CLI 包，保留读取模块。不要混用组件版本或绕过校验。若官方包仍失败，反馈程序版本和错误码即可，无需发送密钥。
