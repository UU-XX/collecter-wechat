# 隐私与数据

## 本机处理

Collecter 的读取、导出、浏览和普通统计在本机完成，不需要登录 Collecter 平台。程序不提供自动上传聊天或后台定时采集。

源微信数据库按只读路径处理，导出写入独立结果目录。多个数据库分片不是同一时刻的联合快照，采集说明会记录实际读取范围及完整性边界。

## AI 分析

三种分发方式的模型处理位置需要分别理解：

| 使用方式 | 聊天内容交给谁 |
| --- | --- |
| Skill | 加载该 Skill 的 AI 宿主及其配置的模型；云端宿主可能将所读内容发送到其服务 |
| Python / CLI 的本地统计 | 不发送到模型 |
| Python / CLI 的模型总结 | 发送到用户配置的模型接口，可以是远程服务或本机服务 |

“本地导出”不等于“AI 分析完全离线”。启用分析前，应了解所选宿主或模型服务的数据处理方式。

Python / CLI 总结请求包含所选记录的正文、发送人、时间及本次分析编号；汇总阶段发送此前生成的摘要。不会把图片、语音或附件文件作为模型输入。每次内容总结单独确认，模型配置本身不代表发送授权。

Skill 在执行读取和分析前应说明本次范围。安装或启用 Skill 不等于授权访问全部账号、全部历史或向其他服务转发记录。

## 配置、缓存与日志

Python / CLI 默认数据目录为 `%LOCALAPPDATA%\WechatLocalCollector`。数据库密钥缓存和模型设置使用当前 Windows 用户的 DPAPI 保护；这不表示用户导出文件本身也被加密。

模型诊断日志记录请求阶段、日期、计数、完成状态和受控错误，不保存聊天正文、模型思考、API Key 或完整服务端响应。普通导出、HTML、每日总结和总体总结仍可能包含私人内容及发送人信息。

Skill 宿主可能另有会话历史、日志、同步或工具输出记录，这些由宿主设置管理，不属于 CLI 日志。

## 用户文件

结果保存位置由用户选择，已有数据不因新版安装自动迁移或删除。增量和续导生成新目录，不直接覆盖原任务。

反馈问题时通常只需提供版本、系统、错误码和阶段。不要公开聊天正文、原始数据库、密钥、模型配置、API Key 或包含私人内容的截图。
